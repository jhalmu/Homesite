# Documentation

This directory contains user guides and technical documentation for the Homesite application.

## User Guides

### [Social Media Feed Adapters](guides/SOCIAL_MEDIA_FEEDS.md)

Learn how to aggregate content from multiple social media platforms into a unified feed.

**Supported Platforms:**
- RSS/Atom/JSON feeds
- Mastodon (Fediverse)
- Bluesky (AT Protocol)
- YouTube
- Twitter/X (via RSS bridges)
- Instagram (via RSS bridges)

**Topics Covered:**
- Getting started with feeds
- Platform-specific configuration
- Managing and organizing feeds
- Background refresh system
- Troubleshooting common issues
- Best practices
- Developer API access

[→ Read the Social Media Feed Adapters Guide](guides/SOCIAL_MEDIA_FEEDS.md)

### [Username Routing System](guides/USERNAME_ROUTING.md)

Learn how to claim custom usernames for personalized profile URLs.

**Key Features:**
- Custom @username URLs
- Profile page customization
- RSS/Atom/JSON feed integration
- Username change tracking
- Reserved username list

**Topics Covered:**
- Setting up your username
- Username validation rules
- Profile URL structure
- Feed URL formats
- Changing usernames
- Technical implementation

[→ Read the Username Routing System Guide](guides/USERNAME_ROUTING.md)
